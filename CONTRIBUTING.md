# Contributing

Contributions should be small, reviewable, and consistent with Privacy Pump terminology and privacy guarantees.

## Before submitting

1. Do not use real wallets, users, transactions, member relationships, credentials, or production endpoints.
2. Run `node scripts/policy-scan.mjs`.
3. Run repository-specific format and test commands.
4. Update architecture, threat assumptions, vectors, and changelog when behavior changes.

Changes affecting cryptography, serialization, authorization, fund movement, privacy claims, or generated interfaces require security-owner review.

By contributing, you acknowledge that licensing is under review as described in [LICENSE_STATUS.md](LICENSE_STATUS.md).
